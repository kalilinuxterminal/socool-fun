# The Wise Trader

Mobile-first static landing page for `socool.fun`. Open `index.html` directly or serve the folder with any static web server.

## Files

- `index.html` contains the sales page, the three Whop links, and the shortened educational disclaimer.
- `styles.css` contains the black-and-gold system, mobile-first layout, and reduced-motion styles.
- `script.js` handles one-open FAQ behavior, scroll reveals, and the sticky header.
- `favicon.svg` is the W-arrow mark.
- `CNAME` sets the custom domain to `socool.fun` for GitHub Pages.

The hero uses CSS only. The page has no photographic assets, tracking scripts, market-data feed, or performance claims.
