# The Wise Trader — static redesign

A dependency-free, responsive landing-page concept built as a clean static export. Open `index.html` directly or serve this folder with any static web server.

## Files

- `index.html` — semantic page structure, original educational disclaimer, metadata, and Whop calls to action.
- `styles.css` — responsive charcoal/teal visual system, diagrams, and reduced-motion styling.
- `script.js` — scroll reveals, mobile navigation, and an illustrative canvas chart that pauses offscreen.
- `favicon.svg`, `og-image.svg` — matching WT monogram assets.

The chart values and diagrams are illustrative only; there are no market-data feeds, tracking scripts, third-party redirects, or performance claims.
